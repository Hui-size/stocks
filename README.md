# A股短线研究助手

这是一个基于 Python + Streamlit + pandas + Plotly + AKShare + scikit-learn 的 A 股短线研究项目。当前版本聚焦单只股票技术分析、未来 1-3 日走势预测、模型回测和 Markdown 报告导出。

项目不做自动交易，不提供买入或卖出建议，不输出“必涨”“必跌”等确定性结论。所有预测都只表示模型基于历史量价数据得到的短线倾向。

## 功能

- 个股技术分析：K 线、成交量、MA5、MA10、MA20、MA60、MACD、RSI、BOLL 和文字分析
- 未来 1-3 日走势预测：分别输出 1 日、2 日、3 日预测方向、上涨概率、震荡概率、下跌概率、置信度、依据和风险提示
- 次日涨跌幅与价位区间：展示下一个交易日上涨、震荡、下跌三种情景的概率、涨跌幅区间和对应价格区间
- 预测复盘与自我修正：记录每次预测，后续交易日行情更新后自动核对实际走势，统计准确率和常见错判类型
- 模型回测：使用历史滚动训练方式展示最近 60/120 个交易日准确率、1/2/3 日准确率、混淆矩阵和实际走势 vs 预测走势
- 分析报告：导出 Markdown 个股分析报告
- 自选股：保留自选股本地保存能力，方便快速选择股票

## 预测数据

预测模块优先使用 AKShare 前复权行情：

```python
ak.stock_zh_a_hist(
    symbol="600519",
    period="daily",
    start_date="20200101",
    end_date="20261231",
    adjust="qfq",
)
```

如果该接口因网络代理或数据源问题失败，会尝试 AKShare 备用日线接口 `stock_zh_a_daily(..., adjust="qfq")`。如果仍失败，页面会显示友好提示，不会崩溃。

如果历史数据不足 250 个交易日，系统会提示“历史数据不足，预测可靠性较低”。

## 预测模型

短线预测模型以样本外稳定性和可解释性为主：

- 候选模型：`RandomForestClassifier`、`ExtraTreesClassifier`、`LogisticRegression`
- 使用比例化趋势、波动率结构、ATR、布林带位置、量价和 K 线结构特征，减少价格尺度漂移
- 数据不足或模型训练失败时：规则模型
- 使用两个带预测周期隔离区的滚动时间窗口，避免 2-3 日标签跨入验证期并控制首次加载耗时
- 不随机打乱数据
- 不使用未来数据训练当前预测
- 同时评价平衡准确率、概率对数损失和跨阶段稳定性，融合两个表现较稳的候选模型
- 近期标签采用指数时间衰减，使概率更快适应上涨、震荡、下跌状态切换
- 预测与滚动回测共用同一套模型和概率融合流程
- 当本地复盘样本足够时，会根据历史错判类型做保守的反馈校准

预测标签规则：

- 默认按每个历史时点的近 20 日波动率和 1/2/3 日预测周期自适应计算阈值
- 未来收益率高于正阈值：上涨
- 未来收益率低于负阈值：下跌
- 介于正负阈值之间：震荡

也可以在左侧边栏切换为手动固定阈值。

## 预测复盘

系统会把每次 1-3 日预测临时记录到本地文件 `prediction_feedback.json`。当后续交易日行情可以获取后，页面会自动核对：

- 实际走势是上涨、震荡还是下跌
- 本次预测是否正确
- 1 日、2 日、3 日分别的历史准确率
- 常见错判类型，例如“下跌 -> 上涨”

这些复盘数据会显示在“1-3 日走势预测”页面的“预测复盘与自我修正”模块中。样本足够后，系统会对反复错判的方向做轻量概率回拨，但这仍然只是一种辅助校准，不代表未来一定准确。

## 次日价位区间

“1-3 日走势预测”页面会额外展示下一个交易日的情景区间：

- 如果上涨：预计上涨幅度区间和对应价位区间
- 如果震荡：预计震荡幅度区间和对应价位区间
- 如果下跌：预计下跌幅度区间和对应价位区间

该区间基于历史收益率分布估算，会随最新行情、预测阈值和复盘校准变化。它不是确定目标价，也不构成买卖建议。

```

```

## 页面使用

左侧边栏包含：

- 股票代码
- 分析周期：30 / 60 / 120 / 250
- 预测阈值
- 功能选择：
  - 个股技术分析
  - 1-3 日走势预测
  - 模型回测
  - 分析报告

## 重要说明

短线预测只基于历史 K 线、技术指标、波动率、成交量和 K 线形态等特征。它无法覆盖突发公告、政策变化、市场情绪急剧变化等因素。

回测结果只说明模型在历史滚动验证中的表现，不代表未来一定准确。
